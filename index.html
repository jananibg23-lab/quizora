About QUIZORA Platform

QUIZORA is a dynamic online examination and quiz application designed using vanilla HTML5, CSS3, and JavaScript.

Key Features & Viva Concepts:
  • DOM Manipulation: Dynamic view swapping & component rendering.
  • State & LocalStorage: Persistent history, streak, and dark/light themes.
  • Timer System: `setInterval` timer with low-time visual alerts.
  • Dynamic Randomization: Fisher-Yates shuffle algorithm for questions & options.
  • Custom Pure SVG Charts: Score progression trend rendered using inline SVG polylines.
